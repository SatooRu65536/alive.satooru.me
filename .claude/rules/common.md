# 共通ルール

## 言語

- すべてのユーザー向けの応答は日本語で行うこと

## 一次ソースの引用がない応答では断言の語彙を使わない

次の語彙を使用する場合，必ず一次ソースとなる URL などを明示すること．
明示しない場合，これらの語彙を使ってはならない．

### 対象の語彙

- 公式
- 慣習
- 推奨
- ベストプラクティス
- 必要
- 必須
- 不可欠
- 適切

### 一次ソースとして応答内に明示できるもの

- 公式ドキュメントの URL（バージョンを明示すること）
- `node_modules/<パッケージ>/` 内のファイルパス
- `CLAUDE.md` / `.claude/rules/` 内のファイルパス
- プロジェクト内ファイルのパス

確認先の優先順位は次の通り:

1. `node_modules/<パッケージ>/` 内のソースコード・型定義
2. GitHub リポジトリ
3. 公式ドキュメントの詳細な説明ページ

公式ドキュメントのサンプルコードは最小限の例であり，制約を示すものではない．

### 代替表現

一次ソースを明示しない場合は上記の語彙を避け，次のように記述する

- 〜と思います
- 〜かもしれません
- 〜の可能性があります

### 検証

以下の手順をチェックリスト形式（`- [ ]` / `- [x]`）で表示し，1項目ずつ結果を記載すること．

1. 変更したファイルの読み直し
   - `Read`ツールで変更した全ファイルを読み込み，ユーザーの要求事項が反映されているか確認する

2. 記述内容の裏取り
   - 変更内容の中で事実を主張している箇所（ファイル構造，コードのパターン，行数等）を列挙する
   - 各主張について，根拠となるファイルを`Read`ツールで実際に読み，事実と一致するか確認する
   - サブエージェントの調査結果の転記であっても，自分で読んでいなければ未検証として扱う
   - ファイルパスが存在する行数が合っているだけでは裏取りとみなさない

3. ルールとの照合
   - `Read`ツールで以下を読み込み，変更内容がルールに準拠しているか確認する：
     - `CLAUDE.md` および `.claude/rules/`配下の該当ルール

4. 第三者視点チェック

   自分自身では実施しない．別エージェントに委譲する．変更の種類に応じて，該当するエージェントを並列で起動する（同じエージェントを重複起動しない）．
   第三者が先入観なくファイル全体を読み，独立した視点で問題を発見することが目的である．伝達内容を最小化することで，自分のバイアスがレビューに混入することを防ぐ．

   エージェントに渡してよいもの（これだけを渡す）:
   - レビュー対象ファイルの絶対パス
   - 想定読者・ファイルの目的
   - 客観的に検証可能なレビュー観点，ユーザーから明示的に提示された要求仕様（あれば）

   エージェントに渡してはいけないもの:
   - 会話履歴・議論経緯，変更の意図・背景・設計判断・解釈
   - 見て欲しい箇所への誘導

5. 報告内容の吟味

   報告された各懸念について，以下を独立に行う．

   - 仕様・要求・適用ルールと突き合わせ，懸念の妥当性を判定する
   - 採用・却下のいずれかに判定する．却下する場合は，コード・仕様・ルールのいずれかに具体的な根拠を示す
   - 採否の判定結果と，却下した懸念およびその理由を，ユーザーに提示する

## コマンド実行の制約

- `npx` を使用してはならない
- CLIツールを実行したい場合，まず `package.json` の `scripts` に該当コマンドがないか確認し，`pnpm run` で実行すること
- `scripts` に該当コマンドが存在しない場合のみ，`pnpm exec` を使用すること
- `pnpm run` でも `pnpm exec` でも実現できない場合は，ユーザーに状況を説明し，対処方法の選択肢を提示すること
- ユーザーに無断で `kill`，`pkill`，`killall` などのコマンドや，開発サーバー・プロセスの停止操作を行ってはならない
  - ただし自分で起動したプロセスは，ユーザーに通知した上で停止してよい
  - プロセスを停止する必要がある場合は，停止対象と理由をユーザーに説明し，実行前に許可を得ること

## 検証の誠実性

動作するはずのような抽象的な自己宣言で済ませない．
検証したと述べるときは，その内容に応じて以下を提示する．

- 実行したコマンドと出力
- 参照したファイルの絶対パスと，関連する行番号または引用
- 動作確認の手段（実行したテスト，出力，ログ等）
